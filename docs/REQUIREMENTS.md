# EasyGot 需求基线

确认日期：2026-10-24。目标：个人在多台 Android 设备使用，不注册账号。开源至 weimanmk/EasyGot，GPL-3.0-only。

1. 离线：浏览题库、答题、查看已有解析、保存错题/笔记/学习进度，阅读教材及搜索原文。
2. 题库：规范 JSON 导入导出；单选、多选、判断、简答及其他主观题。参考答案、解析、章节、知识点、分值、来源和严格要求可携带。
3. 作答：文字输入、照片/手写图片；逐题即时反馈、计时模拟整卷提交、章节/知识点练习、错题复习。
4. AI：自配 OpenAI 兼容地址/Key/模型。评分与图片理解共用视觉模型；语义等价和部分分默认允许，题目或教材严格要求优先。
5. 资料：文字PDF、TXT、Markdown、Word；识别文件内图片。教材问答标注文件及页码/段落；依据不足明确说明，外部内容区分来源。
6. 轻量 Agent：检索、识图、评分、知识点整理、复习计划、出题。已有题库/笔记修改需确认，写入可恢复历史版本；AI 新题先预览编辑再入库。
7. 参考考纲、往年试题和个人错题，控制章节、知识点、题型、题量、难度及权重，区分 AI 新题和原题。
8. WebDAV：全部学习数据含教材和图片同步；冲突保留双方；HTTPS传输、云端明文可读。凭据仅存各设备。
9. 搜索：优先实现 DeepSeek 最新 Search/Fetch API，搜索配置独立于评分模型。
10. GitHub Actions 构建 APK，版本标签触发 Release。正式签名使用持久私钥和 Secrets；没有私钥时仅能提供明确标注的测试签名预览。

首版取舍与文件大小、页数、同步边界在 README 中列出，不能将预览版本描述成已完成真机验收的稳定版本。
