# 测试与验收

## CI

`gradle testDebugUnitTest lintDebug assembleDebug`

单元测试覆盖：多选乱序及重复答案、单选非法答案、判断题布尔值、AI越界评分、并发版本冲突/显式合并、版本环/缺失父链/跨记录链接、DeepSeek官方请求字段和Unicode长度、考纲配比。

## Android人工验收（尚需真机执行）

1. 导入示例题库，断网逐题作答；重开应用，从学习页继续，查看错题及笔记。
2. 模拟考试至少1分钟，后台停留超过截止时间后回来，确认自动交卷；未作答客观题0分，主观题待评分。
3. 配置支持图像/工具调用的模型，分别提交文字、手写图片；验证部分分、strictRequirements及教材strictRules优先，越界评分不入库。
4. 导入含图片DOCX、文字PDF、扫描PDF、TXT/Markdown；断网查原文，联网识别图片，核对页码/段落及断点恢复。
5. 配置DeepSeek Search Key，勾选联网，确认有外部标题/URL；不勾选不能联网搜。模拟401/402/429并验证错误可恢复。
6. 勾选考纲/往年试题，给定类型配比、难度、权重和错题，生成后校验、编辑、确认；确认前正式题库不增加。
7. 两台设备共享WebDAV：先同步基线，再离线编辑同一道题/笔记，分别同步。冲突双方都可见，选定后双设备再次同步一致。素材不可读或SHA256不符时不导入日志。
8. 导出完整JSON备份，清空测试安装后恢复；题库、教材、图片、会话/错题可用，设置中API Key为空。
9. 旋转屏幕、低内存进程恢复、系统图片选择器、Android 8/12/15/16的系统边距与返回行为验证。
10. 配置四个签名Secrets并打新标签；确认APK签名指纹跨版本一致，安装升级不丢数据。

不将协议测试等同于真实服务联调，不将构建成功等同于真机体验通过。
