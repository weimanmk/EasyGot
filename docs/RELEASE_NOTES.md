EasyGot 0.2.0-alpha.1 开发预览

- 蓝色图标、圆角卡片、浮动底部导航和状态栏安全区。
- 助教移为可拖动悬浮球，带入当前题目/资料，题库可持久关联教材、考纲、往年试题。
- API Key支持直接粘贴、显示/隐藏和原生输入框长按粘贴。
- 全题型/整页/多页照片识题，预览编辑后入库。
- A4 PDF作答卷与独立解析卷，纸上作答计时、多页照片按固定题号识别、核对后评分、进度与错题记录。

ARM64 Android 8.0+，Rust界面与业务。当前为测试签名 .preview 包；0.1升级到0.2可能需先备份后卸载旧包，后续预览使用Actions缓存签名。真机、真实视觉模型和多设备WebDAV仍需联调。复杂公式按文本显示，图形题识别后应核对并补充题干图。
