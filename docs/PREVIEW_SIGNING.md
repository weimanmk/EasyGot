# 开发预览签名

从 0.3.0-alpha.2 起，ARM64 预览明确使用 `EASYGOT_PREVIEW_KEYSTORE` 指定的私有构建路径；Actions 缓存该目录，并用 `preview-certificate-sha256.txt` 锁定公开证书指纹。证书来源：Actions `40146186482`，首次修复构建。私钥不进入源码、发布附件或验收截图。

原先缓存 `~/.android/debug.keystore` 的构建日志明确报路径不存在，未成功保存。实际核对 v0.2.0-alpha.1、上一轮 Slint APK 和首次字体修复 APK，签名均不同；此前“后续预览保持签名”的描述不成立。旧安装包可能无法覆盖安装，新版无法恢复旧构建遗失的签名。迁移前必须先在旧版导出完整备份，核对文件后再迁移；新安装合并导入备份，模型/同步凭据需重填。

缓存不是私钥备份。公钥锁定后，如果缓存丢失或证书变化，构建会失败，禁止悄悄生成另一把密钥。正式发布仍需用户持有、备份的长期签名密钥与仓库 Secrets（README 列出），本开发预览不能代替正式签名。
